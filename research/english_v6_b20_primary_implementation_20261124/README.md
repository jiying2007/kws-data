# B20 frozen-model primary evaluator — INERT overlay

This implementation is prepared for the separately registered B20 full source assessment. It does not run source synthesis, ASR, KWS, training, export or parity during preparation or contract tests. It does not open a replica. The earlier B17 and B18 source STOP outcomes remain sealed.

B19's original diagnostic evidence was authenticated independently by the source owner and reviewer: 48 attempts, 48 returns and 48 valid payloads, with all three diagnostic arms at 16/16. This supports a new complete registration. It is not source admission, KWS quality evidence or evidence that the changed rate caused an improvement.

## Execution remains closed

`automation/english_v6_b20_primary_inputs.json` has `scoring_allowed: false`. Every future source, SCREEN and native-proof input is null; no actual primary predecessor is invented. The producer inventory is non-executable until its actual successful B20 source workflow bytes and all input provenance are authenticated and separately reviewed. The source-only assessment and its raw evidence do not themselves authorize any KWS call.

The first operation in every executable evaluator entry is the closed scoring check. `check` is metadata-only and reports zero source calls, zero PCM reads and zero model calls. No B17 or B18 registration is changed by this overlay.

The scoring event must use its actual unique reviewed parent, the designated public branch, attempt 1 and a workflow-only opening commit. The scientific SPEC keeps `prepared_parent: null` permanently and names `parent_authority: reviewed_workflow`; the actual parent is supplied only by the reviewed workflow's two replacement slots. It is checked against checkout HEAD^1, the event's `before` value and the unique parent returned by GitHub. This avoids asking a Git commit to contain its own hash. A saved consumed marker or any previous execution of this scoring workflow blocks replay, including after an earlier marker disappears or expires. Actual-head source and evaluator Python dependency bytes, role-specific registration resources, workflow bytes, the input SPEC and the producer manifest/template are saved and rechecked.

The source owner verifies all three original B19 diagnostic ZIPs and their raw native returns, all historical sources and the context24 supplement. ## Fixed scoring and durable evidence

The same four original PT identities are used. The original B17 snapshot validator checks every learned tensor against its NPZ export, all finite parameters and exact B0/B9/control/challenger frontend equality. The loaded TRAIN receipt must equal the earlier pre-Torch readback.

Each admitted whole original is evaluated at gains 1.0, 0.75 and 0.5 by each of the four models. A forward pre-hook records actual entry and consumes that source/gain/model key before execution. The hard ceiling is 1,404 entries, equal to 12 × (96 + 21). Every returned full tensor is written as an individual fsynced NPY before shape validation; valid finite float32 `(1,T,4)` tensors also enter `ALL_FRAME_LOGITS.npz` as `T×4` matrices. Failed or unknown-consumption entries cannot be repeated.

Records bind the exact admitted ID, PCM, group, cohort, cell, Boolean label and tier in original order. Greedy blank/repeat collapse produces full `[1,2,3]` phrase events and their exact frames. Sample availability is `512 + 160 × event_frame`. The original B14 decision code and assessment bytes remain unchanged. Primary PASS can only authorize an independently authenticated replication opening; it cannot promote a model, change B0, claim target hardware qualification or authorize a product release.

## Offline verification

Seventeen offline fixtures pass in normal, `-O` and `-OO` modes. They use the standard library and, for one constructive activation test, an isolated temporary local Git repository with no remote. They cover closed first-call behavior, a real two-commit workflow-only activation, wrong parent and scientific SPEC mutation, wrong originals/run/head/attempt, dependency/resource/workflow mutation, exact source and saved-row joins, UNKNOWN substitution, whole-history/TRAIN/canary/reserve leakage, blank/repeated/multiple CTC events, zip integrity and consumed-unknown replay. Tests do not import NumPy or Torch, open real audio or model archives, or use the network.
