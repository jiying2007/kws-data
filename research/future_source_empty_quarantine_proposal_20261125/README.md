## 需要决定的具体变更

现有 B24R1 注册要求：任一原生返回为空或无效，整批 SOURCE 停止；R1 来源失败对该注册具有终止性，不允许自动 R2。条款保存在 [原注册说明](../english_v6_b24r1_preparation_20261124/EVALUATION_ONLY_PREREGISTRATION.md) 和 [原 evaluation design](../../automation/english_v6_b24r1_evaluation_design.json)。

本提案建议，只在一个**另行明确批准、事前注册的新评估**中，改变“证据完整的成功空返回”对整批执行的影响：该返回仍无效、没有任何正负票；整条原始音频在五个观察器中的结果全部隔离，不能进入来源准入或 KWS。剩余事前固定的调用继续各执行一次。

| 情况 | 原始样本如何处理 | 整批如何处理 |
| --- | --- | --- |
| 五个原生结果都有效；ASR 文本非空，音素模型的完整 logits 矩阵非空且有限 | 才有资格进入原有准入函数；不保证获得标签或通过来源门槛 | 完成固定计划 |
| 能从原始证据证明成功返回真正的空 ASR 文本 | 整条原始音频隔离，`observed_class=null`，无正负票，零 KWS | 继续剩余固定计划，不重试该调用 |
| 非空内容解析损坏，或类型、编码、形状、身份、哈希、覆盖范围、数值校验失败 | 保留全部原始证据 | 整批 `SOURCE_STOP` |
| 超时、异常、非零退出、缺失或截断原始记录、消耗未知、重复调用、计划外调用或账本不完整 | 如实保留实际消耗和未执行槽位 | 整批 `SOURCE_STOP` |

即使某条原始样本已经因空返回被隔离，它后来出现其他致命错误，整批仍须停止。不能利用另外四票挽救它，也不能把空返回解释为普通语音、真负例或一次 KWS 未检出。

## “成功空返回”的边界

必须先认证调用身份、完整原始输入、唯一一次尝试、实际成功返回及未经变换的原始字节。随后只使用既有严格 UTF-8、最多 4,096 码点、控制字符和显式 Unicode `White_Space` 规则。零长度文本或完全由该白名单空白组成的文本可以属于无效空返回；**不存在的文件不是零长度返回**。不能通过一般的 `.strip()`、删除标点、提取日志行、修补类型或修改提示词得到“空”。目前两次相关失败报告的原始内容均为单个换行符；零字节及其他白名单空白形态是本提案明确提出的未来分类范围，并非声称又观察或验证了这些情况。

Parakeet 还必须证明原始进程启动、退出码为 0、无超时异常，且保留完整 stdout/stderr。Qwen 必须确实返回仅含一个、具有字符串 `text` 字段的原生结果；Whisper 必须确实返回包含字符串 `text` 的原生字典。空列表、`None`、缺字段和错误类型仍须整批停止。

XLSR/LV60 的原生载荷是完整有限的 logits 矩阵。**贪心解码得到空 token 序列不等于原生载荷为空**，其原有含义不变；零字节、缺失或损坏的矩阵仍是致命错误。

这会改变执行编排和账本完成条件，必须使用新的协议版本。原来的字节解析、载荷有效性判断和非空结果准入函数不变，但不能声称原有“所有无效返回都整批停止”的协议完全未变。

## 固定预算与报告范围

每批仍保留全部 120 条原始音频。原有来源规则先决定可观察的 `N` 条：96 条合成原始样本，加上通过既有预观察资格检查的自然原始样本，`96 ≤ N ≤ 120`。未通过这项检查的 `120−N` 条自然样本单独报告并保留曝光身份，不调用观察器、不替换，也不算原生空返回。

五个固定观察器只执行事前确定的 **`5×N` 个槽位，上限仍为 600**。除致命停止外，必须完成全部这些槽位，包括已被隔离样本的其他观察器调用；当 N 小于 120 时，不能为了凑满 600 次额外运行。达到来源最低数量不能提前停止，也不能补人、补样本、重试、重合成或增加 canary。

提案只考虑一次新的评估注册：一个 primary 和一个事前封存的 replication。只有新 primary 的完整数值 PASS 才能打开其 replica；每批上限 600，两个阶段总上限 1,200。任一失败均不能自动产生下一批。四个模型权重、来源格式、B14 来源最低数量、增益、数值质量规则、工程和真实设备要求全部保持固定；不新增训练以规避来源 STOP。控制模型仍是已保存的原始 B23 历史权重，候选仍是原始 B24；沿用 B14 文本中的“same-run control”不代表重新训练了同一作业的对照。

完整的非致命批次必须报告：

`120 = 预观察拒绝数 (120−N) + 空返回隔离数 + 五返回有效但准入未通过数 + 准入合格数`

同时保留全部 `5×N` 个调用槽位的尝试、返回、有效、空、致命及未知状态，并按观察器、来源类型、事前请求类别、固定生成 cell 和人群身份报告覆盖。预观察拒绝与观察后的空返回隔离必须分别统计。所有来源筛选与隔离须在任何 KWS 前冻结，由独立读回从原始字节重算。只有通过原有来源准入的全部合格样本进入 KWS。

## 科学风险没有因此消失

空返回可能与口音、发音、时长、说话人或语音难度相关。隔离它们可能移除较难的正样本，也可能改变负样本构成。规则对正负类别对称、且没有偷看 KWS，仍不意味着缺失是随机的。新的质量结果只能描述通过五观察器准入的子集，不能冒充全部 120 条或真实部署人群的灵敏度。

原有最低数量本身不能限制所有覆盖损失：12 个合成正例、24 个合成普通例及 12 个自然例合计只有 48 条；在八个配对家族、八个自然读者也满足时，数量上可能容许 72/120 条未进入质量评估。提案不偷偷增加新的缺失率门槛；完整分母和分层报告使损失可见，但不能消除偏差。

这是来源失败之后提出的实质修订，不是原协议的独立成功确认。若接受它，仍可能再次失败，也不能仅凭未来的数值 PASS 宣称达到现场 FRR、FAR/小时、延迟或 SSC305 落地要求。

## 原试验与开启条件保持封闭

B24 和 B24R1 的原始失败、全部原始返回和终止状态永久保留；本提案不对旧批次重新筛选、补齐、评分或宣告成功。所有历史 PCM、人群、保留人群，以及 R1 的全部 120 条原始样本和 72 名已用或封存人群，都必须在任何未来新选择前完整排除。本目录尚未选择任何人。

B26 仍只允许由**完整真实 B24R1 PRIMARY `NO_PROMOTION`**触发。来源 STOP 或另一项未来评估的结果不能替代这个条件；旧 B25 条件也不改变。

用户可以保留现行整批停止规则，也可以明确批准上述一次未来协议修订。即使批准，仍须先完成旧失败认证、新注册、完整排除、生产实现和独立读回审查以及精确的一次性激活绑定；本提案自身不打开任何预算。

## 验证文件的用途

[test_admission_invariants.py](test_admission_invariants.py) 仅使用标准库和虚构记录，检查空返回边界、整条原始样本隔离、致命错误优先、既有预观察资格、精确 `5×N` 槽位及上述覆盖风险。它既不认证真实观察记录，也不验证模型质量；没有生产观察器代码或真实音频参与。
