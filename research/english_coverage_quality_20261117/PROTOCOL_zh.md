# 英文唤醒词新增声学条件单次质量实验

日期：2026-11-17（Asia/Shanghai）。本文件在新模型执行前冻结；实际结果另存。

## 目标和边界

当前保留的研究模型为 aug96（公开运行 44021084918）。前两轮相同数据池上的 temporal / dense CE 损失实验没有修复旧 10 dB 开发集漏检，均已拒绝。它们的权重不参与本轮初始化，也不重新运行。

本轮只检验一个新假设：在训练预算、损失、网络、归一化和唤醒门限保持不变的条件下，增加训练噪声强度和背景片段覆盖，能否修复已有英文漏检，同时维持逐样本错误不增加。新增的是声学条件，新增独立原始语音来源为 **0**；本轮不把合成弱意图标签改称真人金标，不把原有背景材料改称可信负样本，不重新消费 TTS、ASR 或音素对齐请求。

固定类别顺序为 0 background、1 Hey Vosen、2 Hey Mero。目标发音为 Hey Vosen `/heɪ ˈvoʊzən/`、Hey Mero `/heɪ ˈmiːroʊ/`；Hey 轻读，名称首音节重读。目标 IPA 是约定，不等于当前音频已经完成人工发音验收。

## 单次新增条件

训练源各生成 new5（5 dB）和 new15（15 dB）两个独立编号条件，共计划 100 条。新编号绑定来源音频摘要、角色、噪声轨道、起始采样点和 SNR；噪声选择域为 `english-coverage-new-acoustic-conditions-20261117-v1`。

每个原始训练源的旧 10 dB、new5、new15 使用互不相同的同角色背景轨道。轨道和偏移由冻结哈希规则一次选定，不因混音失败改选。只混入未经裁切的原始完整合成片段；前导 2.2 秒和后续 0.32 秒原始真实背景保持不变。以完整原始片段 RMS 定义 SNR，信号增益固定为 1；不加入渐变、不削波、不改采样率。超幅、零能量或量化 SNR 不合格的整条条件排除，无替换。

训练前检查每个新条件中每个正类至少保留 2 条原始源和 2 个源家族；背景须覆盖原有全部 4 个训练家族和 8 个文本模板。任一覆盖条件失败则准备失败，不能通过改偏移、改样本或改变预算修复。纯标准库训练预检得到 96 条可用条件，new5 为 32/6/8，new15 为 32/8/10；4 条因 headroom 排除。这不是模型评估结果。

旧 5 dB 评估缓存及其条件 ID 始终只供评估。new5 使用新的训练专用噪声绑定；允许 new5 训练不意味着允许把旧 snr5 开发样本用于训练。

## 特征复用与预算

前端保持原始冻结的一秒 PCM 到 96 维向量的配方和两个 ONNX 权重。每条流首个输出截止于 16000 采样点，后续步长 1280。截止于 16000 至 35200 的前 16 个输入窗口未包含混音片段：必须验证完整 70400 字节前导及每个 32000 字节窗口与原始干净输入完全一致，才能复制原缓存向量；后缀窗口各提取一次。

## 唯一训练候选

从原始 baseline 头初始化，使用冻结的原训练集归一化。头结构仍为 16×96 展平、1536→32→3、ReLU。保持 aug96 正类损失 `-log(mean(p_target))`，背景为逐窗口背景交叉熵的平均值；每步 6 个 bag 等权平均。

新建 AdamW，学习率 0.001、weight decay 0.0001、梯度范数上限 1、随机种子 20261117、CPU 线程数 1，固定 96 次更新。每一步保留 3 个干净类别槽及其原抽样顺序；3 个增强类别槽按 `snr10 → new5 → new15` 循环。第 `step` 步的增强条件为 `step % 3`，条件内部索引为 `(step // 3) % eligible_group_size`，组内保持原 roster 顺序。无中间 checkpoint 选择。

本轮并非新增损失搜索，也不恢复已关闭的同池 loss/seed/threshold/epoch 搜索。只允许这个声学覆盖候选；失败后不得通过修改条件、轮数、门限或种子继续扫描。

## 冻结后的评估与保留门

候选权重保存并冻结后，先在旧干净、10 dB、5 dB 缓存上各评估一次。然后才为原开发 27 条源构造固定 new8（8 dB）条件，使用新的哈希选择域和不同于旧 10 dB 的同角色背景轨道；在共享的新缓存上分别评估 aug96 和新候选一次。

new8 是在训练前预注册、在模型冻结后才物化的新声学条件；其原始说话人、语音和背景池早已暴露，不能称为独立新来源盲测。必须保留全部 27 个计划条件（背景 16、Vosen 3、Mero 8）；任何排除均导致保留门失败，不补样、不改变噪声绑定。

逐样本判定固定为阈值 0.8、连续 3 个输出确认、13 个输出冷却。所有旧条件与 new8 都不允许原正确样本退步，也不允许前导误触发、错误关键词、同词多次触发或负意图触发在任一样本上增加。另须至少修复旧 10 dB 开发集的一个原漏检，旧 5 dB 和 new8 开发条件均须覆盖两个关键词。

计数使用实际观察窗口中的弱意图匹配结果；没有真人词尾标注，不将无事件比例称为现场 FRR，不将事件时间相对音频 EOF 称为词尾延迟，也不把有限合成负例测试换算为小时误唤醒率。

## 落地验证与交付条件

仅公开 GitHub Actions 首次、精确 main 前驱提交的单次 push 可执行模型。PR 和本地校验仅使用源检查、人工构造的固定测试数据及标准库证据审计，不执行 KWS/ONNX/Torch/C/ARM 模型。

同次公开运行将候选导出为固定 `EHKWS01` C 权重，用原 C 代码在 native 和 ARM/QEMU 各重放一次相同保存的特征流。对照同次 Python 保存的逐帧预测，时钟、ready 和事件必须完全相同，最大 logit 误差不超过 1e-4，概率误差不超过 2e-6。记录编译器/QEMU 版本、命令、可执行文件摘要、输入/输出摘要、退出码和独立调用计数。

实际结果另经独立标准库审计：核对输入、噪声选择与 PCM、训练角色/抽样、特征复用、调用预算、冻结顺序、逐帧判定、保留门及已保存 C 输出。只有质量门、证据审计、native/ARM 头部验证全部通过，才以新候选权重封装并集成研究 SDK。

新 SDK 只沿用冻结的通用推理、前端和运行时代码；不继承旧模型完整 PCM 链或硬件验证的通过标记。新模型的完整 PCM 到事件链和 SSC305 实机资格若未执行，明确为 NOT_RUN。formal_training_admitted、training_admitted、human_gold、trusted_negative、pronunciation_verified、model_promotion_allowed、qualification_allowed 始终为 false。
