# 9 个已确认困难负例：一次固定增量训练

## 本轮目标与人工审核

项目负责人针对 `English_KWS_9_Candidates_Review_20261117.zip` 明确反馈：

> 没有唤醒词

该反馈作为包内 9 个候选窗口对 Hey Vosen / Hey Mero 均为负例的审核结论，追加于 `OWNER_REVIEW.json`。原审核包、历史 UNKNOWN / UNREVIEWED 记录保持原样，便于核对证据演变。新审核绑定原包 SHA256、每个 WAV 与 PCM 摘要、原句身份和样本区间；不补造逐文件听音过程、个人姓名或用户未提供的审核时间。

9 个窗口共 30.555 秒，来自 8 个原始来源。审核只覆盖这些窗口；8 条完整原句的 59.37 秒及其余 24 条扫描原句不因此获得人工负例标签。原始角色仍为 train，历史暴露状态不变，不进入独立测试集。该反馈也不建立正例发音 gold。

## 可用训练输入

`SOURCE_ADMISSION.json` 与 `audit/audit_source_admission.py` 将实际保存的 PCM、原始时钟、embedding 字节及已消费的 C 前端/静态库绑定起来。当前前端每次读取完整 16,000 个样本，生成图中全局 ReduceMax / clip 的依赖覆盖整个输入，不能只按末 76 帧的局部卷积估算上下文。

16 行 embedding 相距 1,280 samples，完整输入包络为 `[s-35200,s)`。仅保留整个包络落在已审核窗口内的 ready 输出：共 134 个 `16×96` 输入，覆盖原来的 18 个候选 seed。保留原始时钟与完整缓存；不裁窗重算、不补零、不重新调用前端。同一原句的两个候选窗口合计归为一个来源，8 个来源在新增损失项中各占 1/8。

## 冻结训练方案

本轮当前可交付模型仍是冻结声学 embedding 加 `1536→32→3` 分类头，不冒称 FSMN-CTC。强预训练英文 FSMN-CTC 的独立训练与准入目标继续保留。

从 coverage 实际 NPZ 暖启动：SHA256 `75c1d13203f77fcec9b66013bd6fc8c1979cb3397207931eaf31241eeb396a35`。原 96×6 次训练 bag 抽取及原损失公式保持不变，每步增加一个已审核来源的背景交叉熵项，7 项平均。8 个来源按固定排序轮换，各使用 12 次。

固定 96 次 AdamW 更新、672 次训练 bag forward；学习率 1e-4、weight decay 1e-4、梯度裁剪 1、seed 20261117、单 CPU 线程。优化器状态重置；mean96 / scale96 字节冻结。原正例标签仍为 WEAK。训练完成后先冻结唯一候选，再做回归；不按回归结果选择 checkpoint、学习率、seed 或阈值。

## 一次运行与资源边界

只允许公共 `jiying2007/kws-data` 主分支紧接 `c312a6ef2335af0b4d16c17c598693fc95273c0c` 的首次 push、`run_attempt=1` 执行。源码 PR 仅进行标准库与 mock 检查。数值阶段由公共 GitHub Actions 执行，总监督窗口 1,200 秒，覆盖下载、依赖准备、训练和验证；禁止自动重试、二次训练与定时任务。

复用已保存的 coverage / natural32 artifact、特征、旧模型预测及已有 native consumer。新增音频解码、混音、TTS、ASR、前端推理和 C 编译均为 0。新的候选头只回放固定 323 条缓存流：291 条原回归流及 32 条 natural32 流，共 18,982 行 embedding / 14,137 个 ready 输出。旧头不再 forward。

随后用已有 native consumer 单进程读取同一批 323 条流，检查新 NPZ 与 BIN 的实际一致性；logit 绝对误差不超过 1e-4、概率不超过 2e-6，时钟、ready 和事件精确一致。本轮没有完整 PCM 前端重跑、ARM / QEMU 或 SSC305 实测。

## 结果准入与解释

固定门禁包括：

- 291 条逐案例回归中，旧模型已匹配的目标和正确案例全部保留；各类错词、前缀、额外事件等错误逐案例不增加。
- 保留已修复的 10 dB Mero 案例 `enfinal144-5602dd573b0afb64e36b51b2`。
- natural32 完整流实际事件继续为 0；这只说明已观察的行为稳定，并未为未审核音频补标签。
- 134 个已监督输入按 8 来源均衡计算的背景交叉熵降低。这是训练拟合检查，不是独立泛化证据。
- 权重确有改变，归一化字节不变，实际 NPZ/BIN 与 native 回放一致。

逐窗口峰值、连续三帧最小分的最大值以及超过 0.5 的输出数均保留，诊断范围沿用原 ledger 的 `(start,end]` 输出时钟。门禁失败也保留实际权重、训练记录和全部结果，报告拒绝晋级，旧默认模型不被替换；本轮停止，不换参数重训。

本协议不把 0→0 事件写成误唤醒率改善，不报告独立 FAR / FRR，不将研究保留等同于产品晋级，也不声称已经完成 3–5 米、真实口音、长时背景或 SSC305 资源准入。新的人工负例可用于后续质量主线，但需要继续补足独立正例、长时负例和设备测试。
