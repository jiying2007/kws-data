# Coverage 模型自然英语困难候选扫描：固定执行方案

## 要解决的实际缺口

已交付的英文 coverage 模型使用共享声学前端和三类因果头，两个词不重复计算前端。
此前原始 PCM 验证只覆盖五个已观察案例。当前需要把新模型连接到真实自然英语输入，
保存可回收的高分片段及完整来源，为后续数据复核提供具体对象。

本轮固定扫描32个完整自然英语 utterance，总长204.38秒；不重复生成音频，不训练，
不改变模型、阈值、连续确认或冷却。它是候选挖掘执行，不是独立 FAR/FRR 测试。

## 输入与划分

输入来自已固定的 LibriSpeech dev-clean 517句/40人来源记录。原始压缩包 SHA256 为
`76f87d090650617fca0cac8f88b9416e0ebf80350acb97b343a85fa903728ab3`。
来源已被历史模型观察，不能当新盲测集。

旧 bg48 与当前 coverage 使用不同说话人划分。本轮取两套 train 的交集24人，
同时排除两套 development 说话人；再排除被当前40条背景轨消费过的全部114个原始
source_id，剩余241句、1728.065秒。选择只使用固定域字符串、来源ID哈希和说话人轮转，
不读取任何候选模型分数。每句保留完整2.36–15秒范围内的原录音，固定选32句。
实际选中时长为2.545–14.47秒，总样本3270080，预期2174个 embedding、1694个 ready。

每条输入固定 FLAC、解码PCM、原转写文本的身份及来源角色。`prepare_natural32.py`
从原 training/quality artifact 再生 roster；实际执行必须与冻结 roster 字节相同。
FLAC解码后还必须满足 mono/16kHz/PCM16、样本数及原PCM摘要，不做重采样、增益处理、
拼接或EOF补零。每个原 utterance 启动独立流；该裁分方式没有被冒称自然连续场景。

## 模型、执行与真实记账

模型为既有 `coverage-head.bin`，197908 bytes，SHA256：
`d3e39adf72495034de0405abb997b76744885f91868eccfa97ba09b929bc63e4`。
采用原安装版 native C 库和已验证的完整trace消费者；只编译一个消费者，不重建库。
类别为0背景、1 Vosen、2 Mero；阈值0.8，连续三个同类ready确认，13个80ms hop冷却。
输入chunk为320samples，每句首次ready在sample35200；不补零、不在EOF补确认。

唯一执行环境是公开 GitHub Actions，main 的固定前驱首次push，attempt1。
全局监督器限制1200秒，最多32次模型进程；解码、构建和模型子进程共同受监督。
没有失败重试或看到分数后换片段。每个进程先写started再启动，退出、超时和部分
结果均保存；结束时清理子进程组。实际输入、模型、库、源码、score和trace绑定摘要。

声学计算一次后，用保存概率按原float32阈值和sample clock复算当前0.8/3/13规则。
这只是独立核对固定策略，不搜索新阈值、确认次数、VAD或额外抑制规则。

## 高分候选回收

`mine_saved_scores.py` 只读取保存的ready分数及原PCM。满足实际事件或任一关键词
概率>=0.5时，提出前2.4秒/后1.0秒的审核窗口。实际边界夹在原录音内；跨词重叠
窗口合并，同窗口分别保留两个词的峰值、阈值样本和实际事件，避免双计。

候选排序固定为实际事件优先、窗口最大关键词概率降序、recording_id和采样边界；
每来源最多2个、全局最多32个。记录窗口PCM摘要、原source/PCM/trace/model/config
摘要、精确采样边界及复核状态。若没有命中，必须输出空队列及所有来源峰值，不降
候选阈值、重选输入或强凑负例。

所有输出仍是 `UNREVIEWED` / `UNKNOWN_REVIEW_REQUIRED`，`trusted_negative`、
`training_admitted`、`formal_training_admitted` 均为false。不输出空CTC标签训练TSV。
只有具备完整原始事件标签的候选，才可交给已有pipeline `eval/mine_hard_negatives.py`；
该工具仍排除任何关键词正例重叠。模型分数、ASR不一致或不确定读音均不能充当负标签。

## 发音、模型路线和后续验收

本次用户提供的建议文本包含 Mero `/heɪ ˈmɪəroʊ/`、Vosen `/heɪ ˈvoʊsən/`，
与既有模型profile中 Mero `/heɪ ˈmiːroʊ/`、Vosen `/heɪ ˈvoʊzən/` 不同。
本轮不转换发音版本、不生成新正例、不重标历史权重；所有结果明确绑定原模型profile。
统一比较须记录发音差异，不把两套目标的结果合并。目标IPA本身也不是单条录音的发音真值。

中文FSMN-CTC保留原主线；英文已交付baseline仍是共享embedding+因果分类头。
历史GRU、DS-TCN及FSMN命名分支的模型结构与指标按真实证据分别登记，不重命名为
强英文CTC、不因体积宣传更换已验证模型。统一保存证据比较见同仓
`research/kws_unified_evidence_20261117/`，正式横向质量排名必须具备一致的实际语音、
划分、目标发音、曝光用途和评分/阈值选择规程；架构或前端不同本身不禁止整机比较。

本轮新增独立说话人数为0，已确认负例秒数为0。电视、宠物叫声和机器人自播放没有
被本次自然朗读语料代替；已有合成media/motor/playback代理也不算这些真实场景。
独立FAR/FRR、人工发音gold、词尾延迟、INT8全链精度和SSC305实际资源验收分别保留未测。
