# B21 fresh independent source registration

The separately frozen assessment tests the B21 paired blank-inclusive retention
recipe. It retains the existing source and quality minima. B21 source preparation
contains no KWS inference or model selection.

Primary source slots comprise 96 synthetic requests across Piper voice indices
846–869 and 24 whole LibriSpeech originals from 12 new canonical readers.
Synthetic positive length scales remain 1.4 and 1.8; ordinary request formats are
unchanged. Project role is `development` for every original, including natural
audio whose upstream partition is named `train-clean-100`.

All 120 raw originals are retained. Whole natural duration or audio-quality
rejects remain archived but do not enter the native observers. Every eligible
original must return five valid native payloads; a missing, empty or failed return
stops the complete panel. Unknown labels remain excluded from KWS scoring.
Source admission requires at least 12 synthetic positives, 24 synthetic ordinary
originals, eight paired synthetic families, 12 natural originals and eight
natural readers. No source may be substituted after generation or observation.

`ancestry.json` contains all 2,343 previously exposed raw PCM identities, 380
source groups and 300 canonical people, including all 96 B20 sources and all
previously unknown rows. The original B20 source archive authenticates this
checkpoint by exact byte count, SHA-256, whole original readback and its retained
historical receipt. The old 48 source archives need not be downloaded again.
Independent identity lists preserve every old replication reserve. Natural
readers also exclude all 904 canonical Piper voice identities. Primary synthetic
indices 846–869 and future replication indices 870–893 are disjoint from actual
history and old reserves; ten unused final indices remain outside this study.

The new replication requests and natural reader list are metadata only. The
source driver cannot generate them. Actual primary numerical PASS with the
frozen model files is necessary before a separately registered replication
execution. All earlier failed experiments' reserves remain sealed.

The combined artifact stores `MANIFEST.json`, `HISTORY.json`, authorization and
original-source checkpoint bytes, exact source starts, all native synthetic
chunks, all natural FLACs, all PCM16 WAVs, and the transcript-only ranking proof.
`english_v6_b21_source.read_source` returns observer-eligible rows;
`all_original_rows` returns all 120 raw rows for lineage checks;
`screen_document` recomputes the strict five-provider source decision.

The source workflow remains inert until `__B21_SOURCE_MAIN_SHA__` is replaced
with the reviewed actual main predecessor in a single first public push.
It downloads the byte-pinned 6,387,309,499-byte upstream archive once, streams
transcript metadata first, freezes the 24 utterance IDs, and streams only those
24 native FLACs on the second pass. It never decodes replication sources.

Offline validation checks frozen metadata, no-replay event identity, dropped
historical unknowns, source checkpoint corruption, natural ranking/removal,
whole FLAC header/checksum requirements and exact observer denominators. No new
source, observer, KWS or optimizer call was performed during implementation.
